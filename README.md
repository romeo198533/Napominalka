# Напоминалка

Портативная программа напоминаний для Windows 10 и 11. Полностью
озвучивается, управляется с клавиатуры, рассчитана на работу с программой
чтения экрана NVDA.

## Что умеет

Повторение: один раз, по дням недели флажками, или на конкретную дату.
Тип события: день рождения, годовщина, встреча, приём лекарств, другое.

Режим лекарств: название и доза произносятся голосом, расписание задаётся
несколькими приёмами в день, интервалом в часах или раз в несколько дней.
Курс можно ограничить числом дней. Клавиша 1 — принял, 2 — отложить,
3 — пропустить. Если не ответить, программа дожимает напоминание и ведёт
журнал приёма.

Ещё: своя мелодия на каждое напоминание, назначаемая горячая клавиша вызова
окна, пауза на время, отчёт о пропущенных напоминаниях после включения
компьютера, экспорт и импорт списка, проверка обновлений на GitHub.

## Портабельность

Все данные лежат в папке рядом с `Напоминалка.exe`:

    напоминания.txt   список напоминаний
    настройки.txt     настройки, правятся и в блокноте
    журнал.txt        журнал приёма лекарств
    состояние.txt     служебный файл, хранит время последних срабатываний
    Мелодии\          папка для своих мелодий (wav, mp3, wma)

Пути только относительные. Папку можно перенести на флешку — ничего
не сломается. Встроенная мелодия `по умолчанию.wav` распаковывается
из программы при первом запуске, поэтому даже один exe без ничего
рядом работает и звучит.

## Сборка

Собирается кросс-компиляцией с Linux, на выходе готовый exe для Windows
x64. Нужен .NET SDK 8 в `~/.local/dotnet`.

    ./build.sh

Скрипт сначала прогоняет проверки логики, потом собирает программу
в папку `dist`.

Что происходит под капотом: `src/Core` — логика расписания и файлов,
обычная библиотека без Windows, поэтому её проверки гоняются прямо
на машине сборки. `src/App` — сама программа на WinForms,
`src/Tests` — набор проверок без внешних библиотек.

Отдельная сборка вручную:

    dotnet publish src/App/App.csproj -c Release -r win-x64 \
        --self-contained true -p:PublishSingleFile=true -o dist

## Как сделано

Интерфейс на стандартных элементах Windows — NVDA читает их штатно,
без дополнительных ухищрений. Речь идёт через `nvdaControllerClient64.dll`,
если он найден рядом с программой или в папке NVDA; иначе используется
системный голос Windows через SAPI.

Автозапуск прописывается в пользовательской ветке реестра
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, права администратора
не нужны. При каждом запуске путь в автозапуске проверяется и чинится,
если папку перенесли.

Проверка обновлений читает страницу выпусков GitHub через открытый
программный интерфейс. Токен и пароль в программе не хранятся — для
чтения публичных выпусков они не нужны.
